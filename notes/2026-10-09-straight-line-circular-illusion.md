## 投稿の内容

- 玉がキャラクターの周りを回っているように見える。でも実は、**それぞれの玉は直線上を進んでいる(往復している)だけ**。
- ※ 動画はこの環境から見られないので、以下は投稿文と一般的な仕組みからの説明。

## 仕組み(一般的な説明)

- 「トゥースィーの対円(Tusi couple)」と同じ原理と思われる。
  - 中心を通る直線を何本か、角度をずらして引く。
  - 各玉はそれぞれの直線上を、`位置 = 振幅 × sin(時間 + 位相)` で往復する(単振動)。
  - 各玉の位相を、その直線の角度と同じだけずらす。
- すると、すべての玉が常に1つの円の上に並び、その円が回転(転がる)しているように見える。
- 実際の動きは「直線の往復」だけ。それなのに、脳がまとまりとして見て「回転」と認識する。

## 学べること(演出・実装の視点)

- **安く作れて見栄えがいい。** 各要素は `sin()` 1つで動くので、計算もコードも軽い。物理演算や軌道計算はいらない。
- 「要素は単純な動き + 位相のずらし」で、全体として複雑な動きを作る。ガチャ演出の粒子や、ジェネラティブアートの「規則 + パラメータ」と同じ発想(過去メモ参照)。

## このアプリ(競馬アプリ)での活かし方

- **読み込み中(ローディング)のアニメーション:** 円周を回るように見える点の動きを、`TimelineView` + `sin()` で作る。軽くて飽きにくい。
- **演出:**
  - 予想発表前の「溜め」で、玉が回りながら集まる。
  - 本命の馬のまわりを光が回る。
- **ドット絵との相性:** 動きが単純なので、ドット絵の小さなキャラにも使える(Aseprite のメモ参照)。

## 実装メモ(SwiftUI のイメージ)

```swift
TimelineView(.animation) { context in
    let t = context.date.timeIntervalSinceReferenceDate * 2
    Canvas { ctx, size in
        let c = CGPoint(x: size.width / 2, y: size.height / 2)
        let n = 8, r = min(size.width, size.height) * 0.4
        for i in 0..<n {
            let angle = Double(i) * .pi / Double(n)   // 各直線の角度
            let d = r * sin(t + angle)                 // 直線上を往復
            let p = CGPoint(x: c.x + d * cos(angle), y: c.y + d * sin(angle))
            ctx.fill(Path(ellipseIn: CGRect(x: p.x - 5, y: p.y - 5, width: 10, height: 10)), with: .color(.primary))
        }
    }
}
```

- 「視差効果を減らす」(Reduce Motion)がオンのときは、止めるか簡単な表示に切り替える。
