## 投稿の主張

- Photoshop代替の無料OSS。サイズは11MB。GitHubスター8,000以上。
- 搭載機能:
  - レイヤー / マスク / 描画モード
  - コンテンツに応じた塗りつぶし
  - 被写体の選択 / 背景削除
  - Camera Rawフィルター
  - 修復ブラシ / コピースタンプ
- ※ スター数と11MBはこの環境からは未確認(GitHub APIが使えないため)。

## 確認できたこと(README・docsから)

- **MITライセンス**(Wonder Assembly LLC)。商用利用・改変OK。
- Swift製のネイティブMacアプリ。Xcodeプロジェクトごと公開されているので、自分で機能を足したり削ったりできる。
- 動作環境: **macOS 26以上 + Appleシリコン**。日本語には未対応(英語のみ)。
- インストール: `brew install --cask robbietilton-compositor`、または GitHub Releases から入手。署名・公証済みで、自動アップデートあり。
- 主な機能:
  - **レイヤー:** 調整レイヤー、レイヤー効果(境界線・ドロップシャドウ・光彩など)、クリッピングマスク
  - **選択と修正:** 被写体を選択、コンテンツに応じた塗りつぶし、スポット修復ブラシ、コピースタンプ
  - **フィルター:** Camera Raw フィルター、背景を削除
  - **テキスト:** 文字ツール(段落ボックス、クリッピングマスクとしても使える)
  - **ファイル:** PSD / PSB の読み込み(8bit RGBのみ。CMYK非対応)
  - **書き出し:** PNG / JPEG / PDF
  - **キーボード:** Photoshop風のショートカット
- **AIエージェント対応:**
  - プロジェクト(`.comp`)は「PNGレイヤー画像 + `manifest.json`」のフォルダ。
  - Claude Code などがファイルを書き換えると、開いているキャンバスに約0.5秒で反映される。
  - プラグインもAPIも不要。仕様は `docs/writing-comp-files.md` にある。

## このアプリ(競馬アプリ)での活かし方

- **ストア用スクショの加工を Claude Code に任せる。**
  1. 実機のスクショ(TouchSynthesis のメモを参照)を `.comp` のレイヤーとして配置する。
  2. 見出しテキスト・背景・端末フレームをレイヤーで重ねる。
  3. PNGで書き出し、`asc` で App Store Connect に登録する(App Store Connect API のメモを参照)。
- 同じ構図の画像を、サイズ違い(6.9インチ / 6.5インチ / iPad)やキャンペーン違いで量産する。`manifest.json` を書き換えるだけでできる。
- アイコンやバナーの仕上げも Photoshop なしで済ませられる。

## 注意点

- macOS 26 + Appleシリコンが必須。手元のMacの環境を確認する。
- PSDの互換は限定的。ベクターや縦書きテキストは画像化される。
- `.comp` を AI に書き換えさせる前に、元のファイルのバックアップを取る。
