## 投稿の内容

- 長年愛用しているドット絵アプリ「Aseprite」の解説動画。ドット絵制作アプリに迷っている人向け。

## Aseprite の基本情報(検索結果より。2026年時点)

- **価格:** 買い切りで約 $19.99。サブスクなし。購入先は公式サイト / Steam / itch.io。地域によって価格が違う。
- **ソースコードは公開されているが、オープンソースではない**(2016年の v1.1.8 から独自の利用許諾 EULA)。
  - 自分でコンパイルして**個人で使うのは可**。作った絵の商用利用もOK。
  - コンパイルしたものを他人に配るのは禁止。
  - 自分でビルドするには、CMake・Ninja・Skia が必要で手間がかかる。素直に買うほうが楽。
- **主な機能:** レイヤー、アニメーション(タイムライン・オニオンスキン)、スプライトシートの書き出し / 読み込み、**コマンドライン(CLI)での一括変換**、Lua スクリプト。
- 無料の代わり: LibreSprite(Aseprite の古いオープンソース版から派生)。

## このアプリ(競馬アプリ)での活かし方

- **バッジ・実績アイコンを自作する場合の道具。** 前回の Fantasy RPG Icon pack はライセンス(ゲーム限定)が不明確だった。自作なら権利の心配がない。
  - 例: 馬・蹄鉄・トロフィー・ゼッケンのドット絵。
- **アニメーション:** 小さなドット絵アニメ(走る馬など)を作り、スプライトシートや連番 PNG で書き出す。
  - SwiftUI では `TimelineView` でコマを切り替えて表示する。拡大は `.interpolation(.none)` + 整数倍(アイコン集のメモ参照)。
- **CLI で自動化:** Claude Code から Aseprite の CLI を呼び、`.aseprite` ファイルから @1x / @2x / @3x の PNG やスプライトシートを一括で書き出す。Asset Catalog への配置まで任せられる。
  - 正確なオプションは公式ドキュメントで確認する。
- 宣伝動画・ストア画像にドット絵キャラを入れて、他の競馬アプリとの差別化にする案もある。
