# Claude Motion:チャットだけで解説動画(MP4)を作る

- 出典: X(Twitter)の投稿(ユーザーが本文を共有。URLは未記録)
- 公式発表: https://x.com/claudeai/status/2108271558170976743(2026-10-08、Claude Dashboards と同時発表)
- 保存日: 2026-10-09
- タグ: #Claude #動画 #Motion #HyperFrames #Remotion

## 投稿の内容

- Claude の新機能 **Motion** で、Claude だけで解説動画を MP4 まで書き出せるようになった。
- 同じ note 記事を動画化した比較:

| | HyperFrames(Claude Code と組み合わせ) | Claude Motion |
| --- | --- | --- |
| 作業時間 | Claude の作業が約30分 | 約10分 |
| 作り方 | PC 上で作業する | チャットに台本を貼るだけ |
| 音声 | ナレーション付き | 今回は音なしで依頼(声・BGMなし) |
| 仕上がり | ほぼ同レベル | ほぼ同レベル |

- 「動画づくりのハードルは、操作から文章に移った。」

## 確認できたこと(公式投稿・報道)

- **Team / Enterprise プランのベータ機能。** Pro / Max では使えない(2026-10時点)。
  - Enterprise は初期設定でオフ。管理者が「組織設定 > Artifacts」で有効化する。
- **動画生成AIではなく、Claude がアニメーションをコードとして書く。**
  - そのため、文字・数字・タイミングをあとから自由に修正できる。
  - 実写風の映像や架空の人物は生成しない。
- エディタで直接直すか、Claude に修正を頼む。最後に MP4 で書き出す。
- 想定用途: 四半期報告の30秒解説、グラフのアニメーション化、製品の使い方紹介(オンボーディング)。
- 一部報道では、Adobe / Canva / Runway / Luma への連携にも触れている(詳細は要確認)。

## 3つの動画づくりの比較(過去メモと合わせて)

| | Claude Motion | HyperFrames(HeyGen, OSS) | Remotion |
| --- | --- | --- | --- |
| 作り方 | チャットだけ | Claude Code + Skill で HTML/CSS/GSAP を書いて MP4 化 | React のコードで作る |
| 必要な環境 | Team / Enterprise | PC(`npx skills add heygen-com/hyperframes`) | PC + Node |
| 音声 | 今回の例ではなし | TTS 用の skill あり | 自分で用意(AquesTalk など) |
| 量産・自動化 | 手動寄り | CLI・CI で自動化しやすい | JSON 差し替えで量産しやすい |
| 費用 | プラン料金 | 無料(Apache-2.0 と報道) | 小規模は無料。大きめの会社は有料 |

## このアプリ(競馬アプリ)での活かし方

- **App Store 用の動画:**
  - App Preview と、検索結果・ヘッダー用の Creative Asset 動画(5〜30秒)。
  - アプリの画面とテキスト中心の動画は、コードで作るアニメーションと相性がよい。
- **アップデート紹介:** 「今回の新機能」の15〜30秒動画を、リリースノートから作る。SNS やサポートページに載せる。
- **使い方ガイド:** 初めての人向けのオンボーディング動画。サポートページ(`support.html`)への掲載を想定。
- 使い分け:
  - **Team プランがあれば Motion** で早く1本作る。
  - **個人プランなら HyperFrames か Remotion** を Claude Code で使う。量産するなら SKILL.md 化(ショート動画のメモ参照)。

## 注意点

- ベータ機能なので、仕様・提供プランは変わりうる。最新情報は Claude のヘルプで確認する。
- App Store の App Preview は、実際のアプリ画面を中心にする必要がある(ガイドライン)。装飾が多すぎる動画は審査で落ちる可能性がある。
- 競馬関連の素材(JRA のロゴ、レース映像、実在の馬・騎手の写真)は、許諾なしに使わない。
