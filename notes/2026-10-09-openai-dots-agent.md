## 概要(報道でも確認。細部は記事ベース)

- 2026-09-29 の OpenAI DevDay 2026 で発表された。ChatGPT 内で24時間動く「dot」。モデルは GPT-6 Astra。
- 専用のクラウドPCとブラウザを持つ。自分のPCがオフでも作業を続ける。
- 4,000以上のアプリと接続できる。ChatGPT / Slack / Teams(試験版)から連絡できる。
- 対象プラン:
  - Pro(月100〜500ドル)、Business Premium。
  - Enterprise / Edu / Healthcare は管理者が有効化。
  - 無料版・Plus・18歳未満は対象外。
- 最初の1体はプランに含まれる。dot との会話は利用上限に数えないが、Codex などに振った作業は数える。
- 日本は対象外ではない。ただし順次展開中。

## 使い方の要点

- **頼み方:** 1回で終わる質問ではなく、「担当」として渡す。次の3点をセットで伝える。
  - 何を担当するか
  - どの資料を使うか
  - どこで人が確認するか
- **定期タスク:** 次の4点を指定する。
  - 何を確認するか
  - いつ動かすか(タイムゾーン・終了日も)
  - どんな変化で知らせるか
  - 結果をどこに届けるか
- 出来事をきっかけに動かすこともできる。ただし、Slack をつないだだけでは見張りは始まらない。
- **権限:**
  - アプリごとに4段階: Always ask / Read-only / Low-risk 自動 / All。
  - カスタムルールで行動ごとに決める: 聞かずに実行 / 頼んだときだけ実行 / 事前確認 / 本人に任せる。
  - 例: メールを読む・要約・下書き保存は自動、返信は事前確認、価格変更は本人に任せる。
- **承認の範囲:**
  - 1回承認しても、継続的な許可にはならない。
  - 「下書きして」は「送ってよい」という意味ではない。
- **必ず本人に戻る操作:** パスワード変更、送金、完全削除、不明なソフトのインストール、購入(承認制)。
- **確認と停止:**
  - 作業の確認は Activity、クラウドPCは Computers。
  - 停止は「Pause」。ただし、ほかに振り分けた作業と定期タスクは別々に止める必要がある。

## 注意点(記事より)

- **記憶を個別に消せない。** 消すには dot ごと削除するしかない。
- **悪意ある指示を完全には防げない。** Webやメールに仕込まれた指示(プロンプトインジェクション)への対策は「リスクを減らす」もの。
- **長い作業ほど範囲を外れやすい。** 安全性報告書によると、間に挟む作業を5件から10件に増やすと、範囲を少し外れる動きの検出率が8.6%から19.7%に上がった。
- **動作が不安定という評価もある。** 権限・メッセージの取りこぼし・ブラウザ接続の不具合。
- **クラウドPCは自分のPCのログイン状態を使えない。**
- **小さく始める。** 影響の小さいアプリからつなぎ、結果を見ながら任せる範囲を広げる。

## このアプリ(競馬アプリ)開発での活かし方

- dots は Pro 以上が必要。いま使っている Claude Code(クラウドセッション + Routines / `send_later`)でも、同じ発想の「担当」運用ができる。例:
  - **定期チェック:** 平日朝に、App Store のレビュー・評価、クラッシュ報告、競合アプリの更新を確認する。変化があるときだけ報告させる。
  - **リリース作業の担当:** リリースノートの下書き → スクショの更新 → `asc` での登録。**提出(submit)だけは人が確認する。**
  - **ASO の定期確認:** キーワード別 CPP の CVR を週1回まとめる(App Store アセットのメモ参照)。
- 権限設計の考え方はそのまま使える: 読む・下書きは自動、送信・公開・課金・価格変更は人が確認する。
