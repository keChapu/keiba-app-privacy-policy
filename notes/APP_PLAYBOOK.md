# アプリ制作プレイブック(新しいアプリを作るときに必ず参照する)

ユーザーの指示(2026-10-09):今後アプリを作るときは、以下を必ず参考にして、状況に応じて使うこと。
新しいアプリのリポジトリでは、このファイルの内容を `CLAUDE.md` にコピーするか、手元の Mac の `~/.claude/CLAUDE.md`(全プロジェクト共通)に貼り付けて使う。

## 使い方

- 下の各工程に当てはまる作業が出てきたら、該当する項目を**提案してから**使う。
- すべてを毎回使う必要はない。アプリの種類・規模・段階に合わせて選ぶ。
- 詳しい手順・注意点は各メモ(`notes/` 配下)を読む。

## 1. 課金・収益(サブスクや買い切りがあるアプリ)

- **ペイウォール(課金画面)は、この型をたたき台にする**([詳細](2026-10-09-paywall-redesign-example.md)):
  - 実物(有料で手に入るもの)を見せる。
  - 特典は1行ずつのチェックリストにする。
  - **年額を最初から選んでおき**、割引率を表示する。
  - 月額・年額・買い切りの3択にする。
  - ボタンは「◯日間無料で試す」にする。
- **審査対策(必須):**
  - 無料期間のあとの金額と期間を、ボタンの近くに明記する。
  - 自動更新・解約方法の説明、購入の復元ボタン、利用規約・プライバシーポリシーへのリンクを置く。
  - 価格は StoreKit の `displayPrice` を使う。ハードコードしない。

## 2. デザイン・UI

- **最初に、そのアプリ専用の `DESIGN.md` を作る**([詳細](2026-10-09-design-md-library.md)):
  - 色・文字サイズ・余白・部品・「やらないこと」を決める。
  - UI を作るときは常に DESIGN.md に従う。
- **微調整は言葉で伝えず、スライダー付きの調整画面を作る**([詳細](2026-10-09-tuning-panel-ui-adjustment.md)):
  - SwiftUI では `#Preview` か `#if DEBUG` の調整パネルで作る。決まった値を DESIGN.md に書き戻す。
- **画面を作る前に、実例を参考サイトで確認する**([詳細](2026-10-09-ui-reference-sites.md)):
  - Mobbin / Page Flows / Refero / UI Pocket を使う。**iOS では Apple HIG を最優先する。**
- **演出が必要なときの型**([ガチャ演出](2026-10-09-gacha-animation-artifact.md) / [錯視ローディング](2026-10-09-straight-line-circular-illusion.md)):
  - 溜め → 段階的な昇格 → 開封。効果音・光・揺れ・振動を同時に出す。
  - ローディングは `sin()` + 位相のずらしで作る。
  - スキップと Reduce Motion への対応は必須。有料ガチャを入れるなら確率表示が義務。

## 3. 素材・動画づくり

- **ストア画像:** Compositor で作る(`.comp` を AI が直接編集し、量産する)。`asc` で登録する([Compositor](2026-10-09-compositor-photoshop-alternative.md) / [asc](2026-10-09-asc-api-ai-automation.md))。
- **App Store の新しいヘッダー画像・検索結果アセットも用意する**([詳細](2026-10-09-app-store-header-search-assets.md))。
- **動く文字素材(カットイン・テロップ):** 文字画像APNGメーカーで作る。公開時はクレジット表記が必要([詳細](2026-10-09-text-apng-maker.md))。
- **宣伝動画:**
  - Claude Motion(Team プラン以上)
  - HyperFrames・Remotion(無料)
  - 量産するならショート動画用の SKILL.md を作る
  - 詳細: [Motion](2026-10-09-claude-motion-video.md) / [SKILL.md](2026-10-09-skill-md-short-video-factory.md)
- **ナレーション:** voicebox で、ローカル・無料で作る。他人の声はクローンしない。合成音声であることを明示する([詳細](2026-10-09-voicebox-voice-cloning.md))。
- **ドット絵(ゲーム系・バッジなど):**
  - Aseprite で作る。CLI で @1x / @2x / @3x を一括書き出しする。
  - 円は奇数サイズなら中心が1ドットに決まる。
  - iOS では `.interpolation(.none)` + 整数倍で拡大する。
  - 詳細: [Aseprite](2026-10-09-aseprite-pixel-art-tool.md) / [円](2026-10-09-pixel-art-circles.md) / [学習動画](2026-10-09-pixel-art-school-youtube.md)

## 共通の注意

- 素材・ツールのライセンス(商用可否・クレジット・用途の限定)を、使う前に確認する。
- 課金・位置情報・AI への送信・顔や音声のデータを扱うときは、そのアプリのプライバシーポリシーと App Store のプライバシー表示を更新する。
