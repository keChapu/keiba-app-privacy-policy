## 投稿の主張

- Claude Code に自然言語で指示するだけで、実機の iPhone を人間のように操作できる。API も脱獄も不要。
- テキスト送信の監視やゲーム操作にも対応。アプリのテストや「SNS アカウントのウォームアップ」に使えそう。
- (2件目)ホストやキャバ嬢が客への返信をすべて AI に任せ、売上1億を超えた人もいる「らしい」。

## 確認できたこと(README より)

- **仕組み(iPhone):**
  - Mac の「iPhone ミラーリング」のウィンドウを画面キャプチャする。
  - Apple の Vision フレームワークで OCR し、文字とタップ位置の座標を得る。
  - Mac から HID レベルのイベントを送って、タップ・スワイプ・入力をする。
  - **iPhone 側には何もインストールしない。** 脱獄も Xcode も不要。
- **Android** も対応(adb 経由。macOS / Linux / Windows)。
- 使い方: `phone-harness` コマンドに Python で書く。
  - 補助関数: `open_app` / `tap_text` / `type_text` / `ocr()` / `screenshot()` など。
  - Claude Code 用の `SKILL.md` が付属。
  - セットアップは、エージェントに貼るプロンプト1つで始められる。
  - iPhone ミラーリングのペアリングと、Mac のアクセシビリティ・画面収録の許可は、人が行う。
- **制限:**
  - iPhone のロックを解除するとミラーリングが止まる。
  - OCR は文字しか読めない。ラベルのないアイコンは、スクショ + 画像を読めるモデルが必要。
  - マルチタッチ・カメラ・Face ID の操作は不可。DRM 付きの動画は黒く映る。
  - スマホの接続は常にユーザーの作業。
- 有料の「Phone Harness Cloud」もある(クラウドの Android 端末。最初の100分は無料)。
  - 宣伝文には「stealth」「本物の電話番号」「2FA」とある。

## TouchSynthesis との比較

| | phone-harness | TouchSynthesis |
| --- | --- | --- |
| 必要なもの | Mac(iPhone ミラーリング対応)+ iPhone | iPhone 単体(初回はペアリング用の Mac が必要) |

## このアプリ(競馬アプリ)での活かし方

- **実機での動作確認を Claude Code に任せる:**
  - 主要画面の巡回、文言の確認、スクショ取得。
  - 文字が中心の画面(出馬表・オッズ)は OCR と相性がよい。
- **ストア用スクショの撮影:** 撮影 → Compositor で加工 → `asc` で登録、の流れの入口になる(過去メモ参照)。
- **審査前のチェック:**
  - 初回起動 → ATT ダイアログ → 主要機能、の流れを実機で再現して確認する。
  - Face ID・カメラの操作はできないので、そこは手動で確認する。
- 本格的な自動テストは XCUITest のほうが安定する。phone-harness は「ざっと触って確認する」用途向き。

## 注意点

- **SNS アカウントの「ウォームアップ」や自動返信は勧めない:**
  - 自動操作で人間らしく見せてアカウントを育てる行為は、ほぼすべての SNS の規約(偽の活動・自動化の禁止)に違反する。アカウントの凍結リスクが高い。
  - 「stealth」をうたうクラウドの使い方も同じ。
- **客への返信を AI に代行させて、相手に知らせない使い方は、相手をだますことになる。**
  - 「売上1億」の話は出典不明。
  - 自分のアプリのサポート返信に AI を使うなら、下書きまでにして人が確認・送信する。
- エージェントに自分のスマホ全体(メッセージ・決済・認証アプリ)を操作させるのはリスクが大きい:
  - テスト専用の端末か、テスト用の Apple ID で使う。
  - 購入・送金・送信の前には、必ず人が確認する。
