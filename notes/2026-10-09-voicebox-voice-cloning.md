## 投稿の主張

- Claude が自分の声で喋れるようになった。全言語対応、無料。
- 数秒の音声で声をクローンできる。

## 確認できたこと(README・検索結果)

- **ローカルで動く音声スタジオ**(ElevenLabs + WisprFlow の無料・OSS 代替をうたう)。
  - クラウド不要、API キー不要、文字数課金なし。
- **主な機能:**
  - 声のクローン(数秒〜。精度を上げるなら10〜30秒のクリアな音声が推奨)
  - 音声合成
  - Whisper による音声入力(ディクテーション)
- **8つのTTSエンジン:**

| エンジン | 言語数 | 特徴 |
| --- | --- | --- |
| Qwen3-TTS | 10 | 多言語クローン、「ゆっくり」「ささやき」などの話し方の指示 |
| Qwen CustomVoice | 10 | 9種類のプリセット音声 |
| Qwen VoiceDesign | 10 | 文章の説明から声を作る |
| LuxTTS | 英語 | 軽量・CPU で高速 |
| Chatterbox Multilingual | 23 | 一番多言語 |
| Chatterbox Turbo | 英語 | 感情・効果音タグ |
| HumeAI TADA | 10 | 長い音声も安定 |
| Kokoro | 8 | 50種類のプリセット音声、超軽量 |

- 「全言語対応」は誇張。最大でも23言語(Chatterbox Multilingual)。日本語に対応したエンジンもある。
- **MCP サーバーを内蔵:**
  - `voicebox_speak` を1回呼ぶだけで、Claude Code / Cursor / Cline などが、クローンした声で話す。
  - 用途: 作業完了の報告、質問、通知。
  - 登録例: `claude mcp add voicebox --url http://127.0.0.1:17493/mcp`(HTTP)。stdio 版もある。
  - エージェントごとに声を割り当てられる(どのエージェントが話しているか耳で分かる)。
  - REST API(`POST /speak`)もある。
- Apple シリコンでは MLX(Neural Engine)で高速に動く。

## このアプリ(競馬アプリ)開発での活かし方

- **開発中の通知:** Claude Code の長い作業(ビルド・テスト・ストア画像の生成)が終わったら、声で知らせてもらう。
- **宣伝動画・ショート動画のナレーション:**
  - プリセット音声(Kokoro / Qwen CustomVoice)や、自分の声のクローンを使う。
  - 動画パイプライン(Remotion / HyperFrames / OpenMontage)の音声部分を、ローカル・無料で置き換えられる。
  - 「ゆっくり」「ささやき」などの指示で、読み方を出し分けられる(honoka-tts のメモと同じ発想)。
- **アプリ内の読み上げ機能の試作:** レース結果やお気に入り馬の情報の読み上げ。
  - 製品版の iOS アプリでは、端末内の `AVSpeechSynthesizer` を使うほうが、軽くてプライバシー面も安全。

## 注意点

- **他人の声をクローンしない。** 本人の同意なしの声のクローンは、肖像権・パブリシティ権の侵害や詐欺に悪用されうる。
  - 有名人・実況アナウンサー・騎手などの声の模倣は特に避ける。
  - 使うのは自分の声か、利用許諾済みの声かプリセット音声だけ。
- **合成音声であることを明示する。** 動画の説明欄や、YouTube の合成コンテンツ表示に従う。
- **エンジンごとのモデルのライセンスを確認する。** voicebox 本体は MIT でも、各 TTS モデルは別ライセンス。商用利用の可否を確認する。
- **API に認証がない。** ローカル(127.0.0.1)でだけ使い、インターネットに公開しない。
